# Kaggle Practice

This repository contains my code implementations for various Kaggle competitions and exercises.

## Competitions

| Competition | Description | Code |
|---|---|---|
| [Titanic](Competitions/Titanic/) | Predict survival on the Titanic using PyTorch neural network | [Kaggle_Titanic.py](Competitions/Titanic/Kaggle_Titanic.py) |
